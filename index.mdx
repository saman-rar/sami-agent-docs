Sami is a practical AI assistant built on the [eve](https://eve.dev) framework. It provides a clean chat interface backed by a powerful language model, with specialized skills for eve agent development, technical writing, GitHub pull request descriptions, and shadcn UI component work. Sign in with your Vercel account and start getting things done.

<Steps>
  <Step title="Sign in">
    Visit your Sami deployment and sign in with your Vercel account.
  </Step>
  <Step title="Start a conversation">
    Type your question or task in the message box and press Enter.
  </Step>
  <Step title="Use a skill">
    Describe your task—Sami automatically applies the right skill, whether you're debugging an agent, writing docs, or reviewing a PR.
  </Step>
  <Step title="Continue or start fresh">
    Each conversation is saved as a session. Start a new chat anytime from the top-right button.
  </Step>
</Steps>
