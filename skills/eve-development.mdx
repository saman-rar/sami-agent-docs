The eve skill gives Sami deep knowledge of the [eve framework](https://eve.dev) for building durable backend AI agents. eve is filesystem-first: an agent is a directory on disk, and its instructions, skills, tools, connections, channels, subagents, and schedules are all files that eve compiles and runs. With this skill active, Sami understands that structure and can help you work across every layer of it — from scaffolding a new project to debugging a failing connection in production.

## What this skill covers

- **Agent instructions** — writing and refining the `instructions.md` that defines your agent's identity and behavior
- **Tools and connections** — creating tools that call external APIs, and configuring connections that authenticate them
- **Channels and auth** — adding channels like Slack, setting up OAuth flows, and troubleshooting authentication failures
- **Subagents** — designing multi-agent workflows where a root agent delegates tasks to purpose-built subagents
- **Schedules** — setting up time-based triggers to run agent tasks automatically
- **Evals** — writing evaluation cases to verify your agent behaves correctly across a range of inputs
- **Deployment** — deploying agents, reading runtime logs, and using `eve logs` and `eve traces` to diagnose issues

## Example prompts

```
"How do I add a Slack channel to my eve agent?"
"Write a tool that fetches data from a REST API"
"Debug why my agent's MCP connection isn't authenticating"
"Help me write eval cases for my customer support agent"
```

## Working with eve projects

Sami understands the eve project structure: the `agent/` directory, the root `agent.ts` entry point, `instructions.md`, skills, connections, channels, and subagent definitions. You can ask Sami to scaffold new files, edit existing ones, or review your project layout against eve conventions. When you paste a file or describe your directory structure, Sami maps it to the expected eve layout and suggests changes that fit how the framework actually works.

<Note>
  Sami always reads the bundled eve documentation — found at `node_modules/eve/docs/` in your project — to match your installed version. This means its guidance reflects the exact API and behavior of the version you have installed, not an outdated snapshot.
</Note>
